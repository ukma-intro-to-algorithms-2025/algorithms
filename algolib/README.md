# Algolib - C library

## Description

**Algolib** — C бібліотека, в якій реалізовано структури даних та алгоритми, вивчені під час курсу «Основи Комп'ютерних алгоритмів».

### Data Structures
- **Stack** 
- **Queue** 
- **Deque**
- **Binary Search Tree (BST)**
- **Left-Leaning Red-Black Tree (LLRB)** 
- **Graph**
- **Digraph** 

### Algorithms
- **Sorting**: Insertion sort, Selection sort, Shell sort, Quick sort, Merge sort
- **Geometry**: Points, Convex Hull
- **Graph Algorithms**: BFS
